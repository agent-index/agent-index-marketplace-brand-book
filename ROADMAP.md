# Brand Book — Roadmap

## Current state (1.0.0)
Functionally complete provider with empty content (orgs define everything). Single org-wide enforcement switch; single-provider auto-bind runtime.

## Known limitations / deferred (named in the tech design)
- apply-brand (post-processing) and validate-brand-compliance ops
- artifact-class-scoped enforcement (client-facing vs internal)
- sub-brand template sets; multi-provider bindings
- font file assets (typography = named stacks in V1)
- provider-op script extraction (token efficiency)

## Wishlist
- Import-and-extract from an existing brand guidelines PDF during setup
- Brand compliance reporting across recently produced artifacts
